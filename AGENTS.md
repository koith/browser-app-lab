# Monorepo agent routing

This repository contains unrelated apps. Do not preload other apps' histories, large manifests, or CI logs.

For work specifically in `apps/yui-gallery/` or `apps/mimmi-gallery/`:
1. Read the matching `apps/<model>-gallery/AGENTS.md` and `docs/gallery-archive/DEVELOPMENT-RUNBOOK.md` before planning or editing.
2. Use only the current body of issue https://github.com/koith/browser-app-lab/issues/605 for active work; load past history or relevant excerpts only when needed for a specific failure.
3. Treat actual stored unique photos, replacement quality, verified deployment, and viewer checks as outcomes. A PR or successful CI alone is not a new photo.

For all other apps: do not load or apply gallery-specific guidance.
