## 2026-10-18 실제 작업 및 QA

- [x] 단일 경기의 실제 원본 OBS 46종/242 프레임 모두 GitHub에 존재, 캐릭터 ID 매칭 확인. 이는 **정확한 방향·애니메이션 전체 복원 완료**를 뜻하지 않음.
- [x] 원본 75×141 Registry SAVA는 참가자 아바타, OBS는 실제 주잔 전신, CardData는 캐릭터 카드로 분리. 2026-10-17 원본 역할 QA 통과.
- [x] DMP 타일의 소스 PNG 이미지는 145×97; 프로젝트가 현재 쓰는 웹 투영 pitch는 약 111×75. 이 간격은 과거 EXE의 실제 3D 카메라 값이라고 주장 불가.
- [x] 전투의 CSS 원통형 발판을 금속 상판·4개 분리된 다리·빈 내부가 있는 사진기반 근사 플랫폼으로 교체: `game.js`, `dice-native-battle-podium.css`. 실제 MVE 메시 아님.
- [x] 그 변경에 맞게 `tests/smoke.cjs`의 낡은 '원통형 필수' 주장을 '원본 사진형 개방 플랫폼' 검증으로 교체.
- [x] `tests/dice-original-visual-qa.cjs`에서 실제 타일 상하 A/B 캡처 도구 추가. A/B 결과와 원본 사진을 보고 실제 방향 결정해야 함.
- [ ] **P0 타일 상하 상태**: 실측 결론·브라우저 캡처 승인 전 절대 완료 처리 금지.
- [ ] **P0 원본 배틀 발판**: 추정 CSS 단상을 진짜 추출 메시/프레임으로 교체해야 최종 완료.
- [ ] **P0 원본 주사위**: 원본 모션 픽셀 확인 및 결과별 작동 전에는 '원작 복원 완료' 표시 금지.

## 검증 수준

- VERIFIED-ARCHIVE: CHR/DMP/TIS/OBS/Registry/CardData 파일의 출처·픽셀·숫자/ID·실제 리소스 저장.
- VERIFIED-WEBAPP: 실제 DOM/코드/Chromium 실행으로 확인한 기능/상태.
- INFERRED: DMP 화면 투영, 타일 높이, 전투 플랫폼 CSS, 체스맨 행동 매핑, 결과별 주사위 물리.
- UNVERIFIED: 모든 화면의 2004 픽셀 단위 일치, EXE 원래 3D 메시, 정식 캐릭터별 전투 모션, 상설방의 역사적 목록, 원래 주사위 모델.

## 완료 판정 규정
- 확인한 원본 리소스를 해당 역할에 정확히 사용하고 **실제 게임**에서 화면과 입력이 동작해야 한다.
- 원작 스크린샷/동영상을 게임 배경으로 붙여놓는 정적 오버레이는 복원 완료로 간주하지 않는다.
- 실패한 경로만 기록하고 멈추지 않는다. 관련 추출기/다른 PAK/게임 본편/영상 증거로 반증 조사.
- 원본 수치와 미확인 보정치를 코드 `data-*`, 문서, QA에서 분리한다.
- 동일 화면 실측 A/B, 기존 기능 회귀 테스트, 배포 검증이 성공해야 해당 P0 항목을 완료로 표기한다.
