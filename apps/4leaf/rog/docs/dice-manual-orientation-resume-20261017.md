# 주사위의 잔영 원본 말판 방향·수동 턴·저장 경기 안전성 검증 — 2026-10-17

## 실제 제보와 수정 분리

사용자는 오랫동안 **육각형 말판 자체가 상하 뒤집혀 있음**과 **주사위를 한 번 굴린 뒤 다른 참가자 차례까지 자동 진행되는 현상**을 지적했다. 이 두 문제는 원작 게임의 일관된 외형과 수동 플레이 경험에 심각한 영향을 준다.

- **2026-10-16 PR #85 / VERIFIED-CODE:** `dice-native-tis-orientation.css`가 각 개별 145×97 원본 TIS 아틀라스 발판만 `scaleY(-1)` 처리한다. DMP 경로·깊이·캐릭터 방향·카메라·클릭 좌표는 반전시키지 않는다. `tests/dice-native-orientation-manual.cjs`는 실제 말판 104개와 두 참가자의 주사위 클릭 두 번을 검증한다.
- **2026-10-16 PR #85 / VERIFIED-CODE:** 새 게임의 `game-mode` 기본은 `hotseat`이고 상대도 사람이 직접 주사위를 굴려야 한다. `ai`를 명시적으로 선택할 때만 컴퓨터 상대 자동 턴이 발생한다.
- **기존 저장 경기에 남은 결함:** 예전에 `ai`로 시작한 경기를 저장/복원하면 `navigate('game')`가 AI 상대 차례를 스스로 다시 실행할 수 있었다. 새 게임의 기본 설정 변경만으로 이전 저장 데이터에 있는 자동 진행을 막을 수 없다.

## 이번 추가 구현

- `game.js`: 브라우저에서 AI 저장 경기를 로드하면 `botAutoplay=false`로 되돌린다. 매번 새 방문/복원마다 사용자가 **명시적으로** 자동 진행을 켜야 한다.
- 원본 608×30 `IMG/menu.png`를 대체하지 않고, 웹 복원 보조 기능인 `AI 자동진행: 일시정지/켜짐` 상태 버튼을 제공한다. 역사적 원본 버튼임을 주장하지 않는다 (**INFERRED WEB UX**).
- AI 일시정지 중 컴퓨터 상대의 차례에도 **주사위 굴리기 버튼이 활성화**되고, 유저가 해당 참가자의 주사위를 직접 굴릴 수 있다. `computerPrepareTurn()`에서 임의의 아이템·카드 사용을 자동으로 선행하지 않는다. 수동으로 진행한 한 턴 뒤에도 AI는 재생되지 않는다.
- AI 자동진행을 선택할 경우에는 원래 AI 상대의 자율 턴이 다시 가능하다. 이전에 예약된 timeout은 항상 같은 경기 참조 및 `botAutoplay===true`를 확인하고, 일시정지·다른 경기로 바뀐 후에는 실행하지 않는다.
- 원본 3D 애니메이션/정밀 규칙을 복원한 것은 아니며, 사용자의 플레이 의사에 반하는 자동 롤링만 안전하게 분리한다.

## QA: 조작을 실제로 재현해야 함

- `tests/dice-ai-resume-guard.cjs`: 수동 기본 선택을 확인하고, 명시적으로 컴퓨터 상대 경기를 생성한 뒤 AI 상대 턴을 저장하고 브라우저를 재시작한다. 저장 경기 복원 후 1초 이상 **자동 주사위 없음**, 사람이 한 번 눌렀을 때 **해당 상대 턴 한 번만 진행**, UI에서 다시 자동진행을 켰을 때만 AI가 굴리고, 원본 육각 발판이 세로 반전된 상태에서도 캐릭터·카메라가 바로 서 있는지 검사한다.
- `tests/dice-native-frame.cjs`의 `file://` 출처는 Chromium이 원본 PNG 픽셀을 canvas로 읽지 못해 `tisAlpha=fallback`이 발생한다. 이때 실제 원본 PNG URL을 계속 표시하면 올바른 복원이다. 준비되지 않은 픽셀 수치가 NaN이더라도 잘못된 배경이라고 판단하지 않도록 원본 출처 검사를 분리한다. HTTP(S)에서는 실제 크로마 제거 검사 유지.
- 오프라인 PWA v52와 아카이브, 월드·채팅, 배포된 GitHub Pages Chromium 테스트를 함께 업데이트한다.

## 남은 과제

원작의 육각 타일 렌더링 **각도/카메라 원근**, 고저차와 3D 캐릭터 전투 모션, 실제 단위 턴 규칙에 관한 복원은 여전히 미완성이다. 지금 `scaleY(-1)`은 현재 사용자가 제보한 명백한 뒤집힘을 교정하지만 **원작 3D 엔진 전체를 복원했다는 뜻은 아니다**.
