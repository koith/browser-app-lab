# 4LEAF PC 원작 경기의 턴 인지 수단 — 2026-11-15 교정

## 범위
- 목표: 2001–2004년 PC 4LEAF `창세기월드: 주사위의 잔영`, **2018년 모바일 `for Kakao`가 아님**.
- 역사 화면의 기준: `apps/4leaf/assets/board.jpg`, `battle.jpg` (800×600), 구 서비스 사진, `original/IMG/`의 실제 추출 아틀라스.
- 원작의 **정확한 턴 안내 애니메이션 / 효과음 / 팝업 프레임**은 정적 스크린샷만으로 확정 불가 (UNVERIFIED). 임의 구현을 원작 기능으로 기록하거나 완료 처리 금지.

## VERIFIED-ARCHIVED / VERIFIED-SCREENSHOT
- 실제 참가자 인물 창은 양끝에 위치: 왼쪽 홀수 1P·3P·5P, 오른쪽 짝수 2P·4P·6P. `battle.jpg`에서 확인.
- 원본 `IMG/menu.png` 608×30은 경기 최상단의 원래 메뉴다. 별도의 웹식 ROUND 띠가 원작에 있었다는 증거가 없다.
- `IMG/eventmsgbox.png`는 244×52의 실제 게임 이벤트 메시지 이미지. 현재 웹에서는 보드 위 중앙에서 게임 로그를 표시하는 데 사용된다. **이를 원작의 전용 '턴 알림'으로 단정하지 말 것**.
- `IMG/avatarback.png`는 당시 참가자 초상화 배경. 소스 초상화는 유지한다.

## 확인된 웹앱 결함
- 이전 `dice-turn-clarity.css`는 크기 10–14px의 긴 텍스트를 `#board-area` 상단에 절대배치해, 원래 `eventmsgbox`의 위치와 충돌시켰다.
- 원작 소스 좌표와 무관한 작은 상단 고정 배너로, 현재 플레이어가 **좌우 어느 참가자 슬롯인지** 한눈에 추적하기 어려웠다.

## 이번 교정의 범위
- `game.js::drawBattlePanels`: 이미 계산한 실제 현재 턴을 해당 1P~8P 원본 참가자 슬롯에 연결. 화면 갱신 시 배너 DOM은 **detach→reparent**해 턴이 바뀌면 실제 참가자 카드로 이동하며 초기화나 복제되지 않는다.
- `updateTurnGuidance`: 본문은 현재 경기의 실제 `match.active`, `player.name`, `match.mode`, `busy`를 사용하고, 'N P · 내 차례 / 상대 AI 차례 / 상대방 차례' 와 보조 설명을 분리하여 표시.
- `dice-turn-clarity.css`: 충분한 크기의 임시 접근성 안내를 원본 플레이어 레일 **바로 옆**에 정렬. 800px PC 프레임에서는 중앙의 원본 이벤트 메시지와 좌표가 겹치지 않도록 설계. 650px 이하는 별도 WEB 모바일 대응이며 역사적 2002년 UI라고 주장하지 않음.
- 현재 안내 말풍선/강조 테두리는 **WEB-ACCESSIBILITY, NOT ORIGINAL**. 원작 전용 턴 마커의 실제 모습/동작이 영상이나 원본 실행 자료로 확인되면 반드시 이 임시 요소를 원작 UI로 교체한다.

## 완료 판정
1. Chromium에서 실제 1P 주사위 굴림 이후 진행 턴이 2P로 바뀔 때 **같은 안내 DOM**이 좌측 1P에서 우측 2P로 옮겨짐.
2. 안내 기본 제목 15px 이상. 실제 원본 참가자 아바타를 가리지 않음.
3. 800×600 소스 프레임에서 원본 `IMG/eventmsgbox.png`를 가리지 않음.
4. 기존 주사위/카메라/게임 종료/채팅 기능에 회귀가 없음.
5. 위 검증으로 확정 가능한 것은 **웹 턴 인지성 개선**이지, **원작 턴 연출 복원**이 아님. 원작 애니메이션은 미완료 유지.
