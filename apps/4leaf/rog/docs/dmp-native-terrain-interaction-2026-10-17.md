# 4LEAF 주사위의 잔영 — 진짜 DMP/TIS 지형 탐색과 워프 연결 (2026-10-17)

## 원본에서 검증 가능한 정보 (VERIFIED-ARCHIVE)

- `original/maps.js`의 맵별 배열은 실제 소스 DMP 칸의 정수 `x, y` 격자와 세 번째 **칸/방향 코드** 등을 포함한다. 연결 이벤트 `record[3]===10`이고 유효한 `record[5]`일 때 원본 맵 내 다른 칸을 지정한다. 이 데이터를 `game.js`의 실제 맵 생성·워프 판정도 공유한다.
- `original/tiles.js`에는 칸의 원본 이벤트 유형 및 일부 속성·워프 그룹이 보존돼 있다.
- `original/Tiles/*.png`는 실제 145×97 RGBA 육각형 형태의 원본 판 그림이다. 현재 웹앱의 실제 `.tile[data-original-art]`가 개별 파일을 사용하고 있다.
- `IMG/eventmsgbox.png`는 원본 244×52 게임 메시지용 별도 리소스다. 탐색 안내를 원본 그래픽에 얹더라도 글자 내용·새 인터랙션의 원작 사용 여부는 따로 입증해야 한다.

## 구현 변경 (실제 플레이 연동, INFERRED WEB UX)

- 이전에는 칸을 클릭해도 `game.js::log()`가 개발 로그에만 출력해 사용자 입장에서 실제 행동 반응이 거의 없었다. 이제 **진짜 원본 TIS 칸**을 마우스·터치·키보드 Enter/Space로 선택해 실제 DMP 맵의 칸 번호, 이벤트 종류, 진짜 격자 좌표, 원본 TIS 파일 번호를 확인할 수 있다.
- 실제 DMP 워프 칸의 연결 `record[5]`가 유효하면 **워프 연결 보기** 버튼이 활성화된다. 카메라만 연결된 원본 DMP 칸으로 이동하며, 미니맵과 동일한 `__LEAF_MINIMAP_NAV__.focus()` 경로로 표시 영역을 갱신한다. 이는 **맵 탐색**이지 실전 워프 발동이 아니다.
- `#dice-source-dmp-inspector`는 인게임 원본 `IMG/eventmsgbox.png` 그림을 재사용하는 컴팩트한 *웹 복원 조작 안내*이며, 원작 바이너리 UI로 입증되지 않았으므로 `data-reconstruction="web-inspector"`로 표시한다. 실시간 경기 메시지 `#dice-native-event`나 실제 턴 선택창을 덮어쓰지 않는다.
- 활성 인게임 칸은 인접 육각형을 가린 스크린샷 버튼이 아니라 **실제 145×97 원본 PNG 플랫폼 DOM**이며, 자산의 RGBA와 게임 hitbox를 그대로 보존한다. 선택 강조는 웹 접근성이다.
- **절대 변경하지 않는 값:** `match.players[].position`, `match.active`, `match.history`, 게임 서버 메시지, 정원·온라인 상대, 실제 주사위 판정. 원본 104칸 DMP가 실제 유지된다.
- `MVE` 원본 3D 메시와 **지형 고도/카메라 회전**이 복구되지 않았다. DMP 세 번째 필드를 임의로 높이값이라 가정하거나 그럴듯한 가짜 절벽을 그려 놓고 원작 3D를 복원했다고 주장하지 않는다.

## 검증

- `tests/dice-source-dmp-terrain-explorer.cjs`: 실제 맵 4LEAF의 104개 독립 소스 칸(145×97), 원본 워프 링크, 이동 전·후 게임 기록/좌표/턴 완전 불변, 실제 카메라와 미니맵 탐색, HTML 접근성 Enter·Space, 닫기, 390px 모바일, 브라우저 오류 확인.
- `tests/native-offline-cache.cjs`: PWA v56 첫 오프라인 게임에서도 원본 DMP 탐색과 카메라가 동작하며 게임 상태를 변조하지 않음.
- 로컬 WorldMap·ChatRoom·주잔, 25개 원본 맵, 중앙 채팅, WebRTC, 공개 GitHub Pages Chromium 테스트를 모두 보호한다.

## 다음 최우선 복원 연구

초기 실행 파일 및 MVE/3D 모델 리소스에서 실제 지형 높이·경사·카메라 투영·모션 프레임을 추출할 방법을 찾아야 한다. 현재 저장소의 PNG/JS 추출 자료만으로는 실제 3D 지형을 완전히 재구성할 수 없다. 해당 한계를 유지하면서 맵 데이터/카메라/행동의 실제 소스기반 정합부터 넓힌다.
