## 무엇을 확인했는가

원본 스크린샷 `apps/4leaf/assets/shop_ref.png` (PNG 원본 541×402) 및 원본 설치 파일 `original/CardShop/cardshopback.png` (794×404), `cardshopbutton.png` (500×510)를 **서로 다른 시대의 실물**로 대조했다. 2002년 원본 뒷면의 3×3(9장)을 2004년 사진의 4×2(8장)와 혼동하거나 삭제하지 않는다. 게임 내부 카드를 가짜 화면 캡처의 특정 얼굴로 대체하지 않는다.

## 테스트

- `tests/shop01-2004-real-screen-acceptance.cjs`: 원본 스크린샷 IHDR을 직접 확인하여 541×402가 아니면 실패한다. CSS 클래스만 비교하는 대신 실제 Playwright 브라우저의 `getBoundingClientRect()`를 원래 794×404 원본 좌표로 정규화해 **사진 기준 좌표 15곳 이상** 대조(역산 및 4~6px 근거 오차).
- 실제 보유 카드 27장 예제, 8장 4×2, Normal/Valuable/Rare 탭, 보유 목록 스크롤, 선택 카드 정보, 실 GP 결제, 다음·이전 페이지, 2002년 3×3 복귀 후 **동일 카드 소유·선택·가격·GP** 대조.
- `tests/r21-source-era-shop.cjs`: 실제 2002 원본 화면·2004 사진형 화면 두 세대와 잔액 거래 및 브라우저 저장 유지.
- `tests/shop-original-serial-resale.cjs`: 2003년 역사 운영 공지의 1,000GP 시리얼 지급 카드와 별개 추정 일반 매매 구분.
- Chromium과 WebKit 두 브라우저를 각각 실구동하는 `.github/workflows/rog-r21-source-era-shop.yml`의 동일 PR HEAD 테스트를 수용 조건으로 삼는다. Playwright 캡처 `leaf-shop01-historical-2004-trace-*.png`를 CI 아티팩트에 보존한다.
