## 차이가 확실하게 확인된 부분

1. **전투 발판에 실제 원본 자산 존재:** 과거 main은 추정 CSS 원통/4다리 발판을 그렸지만, 별도 브랜치에서 `winBattle.spr`의 원본 355×113(두 개 금속 발판+VS) 및 222×42 제목을 엄격한 SHA 검증으로 복구했다. 이것은 **원본 2D SPR**이며 3D MVE 메쉬/낙하 주사위와 동일한 것이 아니다. 브랜치 `29b4546d`의 browser smoke는 기존 CSS 다리 4개를 필수 조건으로 하는 오래된 테스트 때문에 실패한다.
2. **보드 2D 픽셀 보호와 역사적 3D 동일성의 구분:** 진짜 TIS 145×97을 150×100 웹 피치로 배치해 26맵 1,920셀 사각형 겹침을 제거했고 현재 카메라는 DMP 경계로 이동 제한을 구현했다. 그러나 2004 MVE 높이·카메라 투영·피사체 접지·타일 측면 가림까지 복원했다고 할 수 없다.
3. **캐릭터 자산 출처:** 보유 원본은 98종 중 64종 281장; 일부 OBS scanline 가로 원점 및 idle/walk/attack/hurt/victory 정확한 행동 테이블이 미해독. 나머지 34종은 카드 초상화만 있고 원본 전신이 아니다. 다른 OBS2/OBS3 원본팩을 엄격히 검색했으나 신규 합격 0종([검증 로그](https://github.com/koith/browser-app-lab/actions/runs/39127531422)).
4. **주사위는 원본 모델이 아님:** 원본 `roll.spr`(4장)와 `eventRoll1.spr`(16장)은 **UI 버튼**. 하늘에서 튕기는 게임 객체는 웹 대체 렌더러이고 D4·D6의 당시 엔진 3D 폴리곤/결과별 궤적은 원본 검증이 없다.
5. **상설방 구성:** 2004 참조는 검정 채팅 로그 좌상단, 입력창 바로 아래, 실 사용자 상단 우측 목록, 하단·앞쪽 가구 및 아바타/말풍선. 라이브 배경과 실제 1인 손님은 보이지만 원작과 다른 방/인원 수 캡처이므로 방ID를 먼저 매칭해야 하고, **원작의 다인 사용자 10명을 가짜 NPC로 채우면 안 된다**.
6. **상점 UI 차이:** 원작 레퍼런스에는 Normal/Valuable/Rare, 카드 4×2, 우측 판매·소유자 목록, 카드정보, GP가 있다. 현재 화면은 재구성 3×3 카드 및 다른 순서의 오른쪽 UI이므로 외형 차이 확실.
7. **배포 수용 결함:** 최신 미병합 source SPR 브랜치의 [browser smoke 실패](https://github.com/koith/browser-app-lab/actions/runs/39128904349) 원인은 새 원본 발판을 올린 뒤에도 CSS 가짜 4다리 필수로 검증하는 오래된 테스트. **테스트를 원본 자산에 맞추되 실제 2명/판정/회귀 조건을 약화시키지 말 것.**
