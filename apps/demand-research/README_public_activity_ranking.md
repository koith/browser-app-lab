# INTERSECTION: 게시글 상단 활동·반응 계정 랭킹

`apps/demand-research/index.html`의 **게시글 탭 최상단**에 표시되는 휘발성 관측 순위입니다.

## 의미 및 계산

- 대상: 현재 조회된 기간 및 텍스트 검색 조건을 만족하는 **공개 원문 확인 게시글**.
- 제외: 광고 의심 글, 제한 또는 민감 콘텐츠 라벨이 지정된 글, 원문 확인이 되지 않은 링크, 클라우드 개인 저장본.
- 기준: 각각의 SNS 공개 프로필 주소. 서로 다른 플랫폼 계정이 같은 실제 사람이 운영하는지 추정하거나 합치지 않습니다.
- 같은 플랫폼·게시글 ID는 중복 계산하지 않습니다.
- 관측 활동 지수 = **게시글 수 × 2 + 관측 활동 일수 × 3 + (공개 반응이 제공된 경우) round(6 × log2(1 + 반응 합계))**.
- 반응 합계 = 공개 API에서 제공한 좋아요·재게시·답글·인용 합계. 플랫폼의 점수/반응 값 의미가 달라 일관된 영향력 측정치는 아닙니다.
- 반응 데이터가 없는 플랫폼이나 게시물은 반응 수를 **미제공**으로 표시합니다. 0건이라는 뜻으로 해석하지 않습니다.
- 상단 제목은 `RANK`. **초기 상위 20개**, `더 보기`를 누를 때마다 **20개씩** 추가하며 남은 계정이 없으면 버튼을 숨깁니다. 플랫폼을 변경하거나 조회 기간을 변경하면 20개로 초기화합니다. 데스크톱은 정확히 10열, 모바일은 정확히 5열 그리드입니다. 초소형 카드에는 **순위·최근 게시글 썸네일**만 표시하며 계정명은 접근성 레이블과 상세 대화상자에서 제공합니다. 최근 게시글에 미디어가 없으면 빈 썸네일 블록을 사용합니다.
- 카드를 클릭하면 대화상자에서 점수, 게시글 수, 활동일 수, 반응 수와 SNS 프로필 링크를 확인할 수 있습니다. 플랫폼 필터와 정렬 선택은 유지합니다.
- 사용자가 기간/검색을 바꾸거나 새 게시글이 들어오면 자동으로 재계산합니다.

랭킹은 **현재 수집기가 실제로 가져온 일부 공개 게시물의 활동·반응 현황**입니다. 실제 전체 SNS 게시량·팔로워 도달 수·소비자 구매 영향력·실제 인물의 영향력을 확정하거나 추정하지 않습니다. SNS마다 수집 범위와 반응 제공 여부가 다르고 날짜별 검색 누락이 있을 수 있으므로 **전체 SNS 순위는 참고용이며 플랫폼별 비교를 우선 권장**합니다. 내용과 계정 추적 이력은 새 모듈에서 저장하지 않으며, Bluesky 기존 활동 여부 확인을 위해 공개 프로필 메타데이터를 읽을 수 있으며, 실패 시 60초 이후 재시도합니다. 프로필 생성일을 모르면 기존 계정으로 단정하지 않습니다. 첫 화면에서는 근거 있는 기존 활동이 없을 때 신규·이력 미확인 탭을 보여 빈 화면을 피합니다.

## 2026-11-03 게시글 UI 변경

- 게시글 카드 오른쪽 위 출처 뱃지는 플랫폼명 텍스트를 숨기고 **로고만** 노출합니다(접근성 라벨 유지). 상세 팝업의 서비스명과 계정 분석 화면은 변경하지 않습니다.
- 헤더의 `INTERSECTION` 제목 바로 옆에 **상품 수요 분석**을 작은 링크 버튼으로 놓고, 탭 아래에 있던 큰 안내 배너는 제거합니다.
