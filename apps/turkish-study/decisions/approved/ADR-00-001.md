# ADR-00-001 — W01/W02 평가 정합
결정: 01이 작성한 교육 목표와 평가 루브릭이 시험의 authoritative blueprint이다. 기존 candidate W01은 L/R/W 각 5문항×5점 vs W01-RUBRIC-r1 듣기/읽기 각 10×2.5, 쓰기 세부 배점, 60분 시간 구성의 불일치. 02는 source of truth인 curriculum-mapping/week01-assessment.json (W02 별도 루브릭도 대조)에 맞추어 새 revision 작성. 기존 질문 ID 보존·새 항목 추가, 학습 범위 벗어나지 않게 함. 03은 향후 평가 UI에서 rubric 기준으로 듣기 대본 숨김, 쓰기 부분 점수/동의 답안, 상호작용 4 criteria, 영역별 25점, 총 80·각 15, 미평가 구분. 05 independent review. Candidate 14일 merge는 작성물 보존이지 학습 승인 아님. P0 status NO-GO until both alignment and actual test passes. 대안(5문항 축소): 목표 커버리지/진단 정보 감소 때문에 채택하지 않음. rollback: 이전 draft revision으로만 복귀, 발행/학습 기록 없음 또는 보존.
