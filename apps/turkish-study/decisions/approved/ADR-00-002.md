# ADR-00-002 — 공개 artifact binding (additive)
현 03 gate는 contentRevision 존재만 검사하고 실제 fetch payload와 연결하지 못한다. RELEASE_MANIFEST.json의 publishedDayIds가 비어 있으면 development mode 허용하되 learner access 차단. 비어 있지 않을 때 contentRevision=정확한 lesson blob 또는 course release revision, artifactDigests={curriculum:{path,sha256},lessons:{path,sha256},assessment:{path,sha256},audioManifest:{path,sha256}}. 필요한 승인 artifact만 manifest에 지정하되 P0는 4개 모두 필수(검증된 TTS만 사용하더라도 승인 음성 manifest 필요). SHA-256은 서빙된 파일 원본 UTF-8 bytes, lowercase 64 hex; JSON 재직렬화 금지, DOM 표시 전에 fetch ArrayBuffer/crypto.subtle 및 parse, offline snapshot에 원본 bytes와 승인 manifest 유지 후 재검증, missing/mismatch fail closed. assessment/audio 각각 승인 대상 ID/revision과 연결. 학습자 데이터 마이그레이션 없음; 승인 없는 외부 API 추가 금지. 03 구현 후 05 온라인/오프라인/변조/캐시 실증. 이전 버전 snapshot은 기존 승인 범위만 검증된 경우 사용, 이전 v0.1.0은 승인 없음. 구현되기 전 정식 출고 불가. 04 ADR-04-001은 후보 검토 지속; 고정 MP3 방식은 재배포 가능한 license/검증·최신 대상에 조건부 채택, session API 통합은 05 증거 및 정확한 revision 확인 뒤 03에 전달.
