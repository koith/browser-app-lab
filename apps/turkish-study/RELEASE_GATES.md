01: D001-D007 목표, 선수학습, 분량·평가 맵 확정. 02: 7일 본문/어휘/예문/회화/듣기·따라말하기/문제·정답·해설 및 주간평가 제공; 일별 60분 분량 검토. 04: 실제 터키어 음성 재생과 청취 검수 (고정 파일 또는 검증된 tr-TR 기기 TTS), 듣기·녹음·자기 비교; AI/STT가 없어도 핵심 학습 가능. 03: 공개 HTTPS 배포, 2인 별도 저장, 시험·복습·출국일·백업/복원, 접근 가능 UI, 출고목록 기반 수업 접근 제어, 서비스워커 갱신. 05: 언어/정답/의존성/음성/실제 공개 URL/PC/iPhone Safari 세로 기능 검증; 두 학습자 간 기록 독립성, 브라우저 재접속 및 백업 복원. 00: 증거 확인 후 Day 1–7 승인.
초기 개발판 공개(테스트)는 정식 학습 출고와 구분. 위험 없는 미검수 문서가 저장소에 공개돼도 학습 UI에서는 차단. main v0.1.1에 gate 기능 구현; 공개 운영 v0.1.1 및 05 독립 검증 미완은 P0 블로커. 03은 release manifest를 로드하고 허용 일자 이외 수업/퀴즈/완료 금지; 장애 시 검증된 캐시나 안전한 안내 화면. ADR-00-002 exact artifact binding 및 ADR-00-001 주간 평가 정합도 P0 필수. URL 404는 P0 블로커, Pages 원인 조사 후 다른 무료 정적 호스팅 비교, 타 프로젝트 설정 변경 금지.
학습 개시 지연 방지: 클라우드 인증/동기화가 늦어질 경우 **검증된 로컬 2인 분리 + 내보내기/가져오기**를 임시 학습판 조건으로 허용 가능. 이는 원래 영구 저장 요구 충족 아님. 실제 재접속·백업 복원 확인, 데이터 손실 위험 및 기기별 분리 명시, 백업 상시 접근, 00이 제한사항 기재 후 P0 승인. 클라우드 도입은 P1 필수, 비용 발생/기존 운영 DB 사용 금지. 학습 기록 이관 시험과 별도 원장 유지.

## 완료 판정
기능 완료 = 요구사항·코드·실제 동작·회귀·접근성 관련 체크·검증 증거·통합 main 확인. 콘텐츠 완료 = 정확한 최종 revision·구조/교차 참조·독립 언어/정답/선수 검수·필요 음성 검수·출처·공개 목록. 연구 완료 = 공식 자료/범위/근거/불확실성 기록. 전체 출시 = 모든 원래 P1/P2 요구 포함. P0 제한 출시를 DEP-05 전체 완료로 세지 않음. 
검수 기록은 실제 파일 hash 또는 commit, 검사 일시, 환경, 예상/실제, 결과, 출처/증거. 원어민 또는 독립 출처 교차 검수 방식 명시, AI 자기검수만으로 독립 검수 판정 금지. 실제 Safari/WebKit 에뮬레이션은 물리 iPhone과 구분; 물리 기기 미검증은 명시하고 해당 실기기 gate를 미통과로 유지. 앱 배포 완료 = HTTP 200 + 정확한 버전/데이터 + 브라우저 렌더링 + 사용 흐름 성공. P0 승인과 정식 배포를 구분하고, 명시된 gate 누락 시 테스트판만.
00이 RELEASE_MANIFEST.json 승인 목록을 05 증거 후 업데이트. manifest는 허용 일자/릴리스 상태를 나타내는 유일 기준, 작성된 lesson 개수와 동일하지 않음. 03이 런타임 enforcement, 05가 차단 테스트. rollback은 직전 공개 artifact/cache revision 복귀, 학습 기록 삭제 금지.

자동 운영은 AUTO_DEVELOPMENT.md 참조. 전체 완료까지 P0/P1/P2를 이어가되 정식 출고 후 실제 운영 검증 전 성공 알림 금지. 최신 공개 appVersion과 후보 main appVersion을 구분한다.
