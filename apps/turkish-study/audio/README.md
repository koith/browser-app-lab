## Runtime proposal (not integrated)
audio/session.mjs exports createAudioSession, findAudio, selectLocalTurkishVoice. Pass baseURL app root ending slash, manifest contract 1.0.0, preview boolean (false default). Invoke play(targetId,exactText,{rate:0.6..1.25,repeat:false}) directly on tap. Draft fixed/any device voice only in preview; production requires approved asset and 03 day gate. Loop only fixed, device manual replay. onStatus emits error/unavailable/playing/ended/recording/recorded. startRecording requires HTTPS, explicit tap; stopRecording returns URL through recorded status; UI plays local blob in audio element, stop it before reference audio. releaseRecording discards URL; dispose on navigation/profile change. No upload, persistence, pronunciation score, or CEFR inference.
