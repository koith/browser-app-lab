## 회귀 테스트

- 기존 두 MOV의 영상·AAC 음성 검증을 유지하고, 첫 오디오 샘플뿐 아니라 2초 입력 중 최소 1.8초를 실제 디코딩하는지 검사.
- 인코더 지연 후 순서·샘플 보존, 버퍼 초과, 파일 쓰기 실패 시 미기록 샘플 보존 검사.
- 마이크 미준비, 녹화 중 한쪽 카메라 정지, 반복·잘못된 타임스탬프 검사.
- Xcode 컴파일 및 iPhone 대상 IPA 재빌드는 GitHub Actions 결과를 기준으로 기록.

## 실제 아이폰에서 우선 확인할 항목

1. 10초 이상 녹화: 전·후면 각각 영상과 음성이 재생되는지, 시작·종료 소리가 실제로 없는지.
2. 검은 화면 진입 → 두 번 탭 복귀: 조작 화면과 이전 밝기가 복원되는지.
3. 녹화 중 잠금·홈 이동·전화 수신: 녹화 종료와 두 파일 저장, 통화 종료 후 수동 재녹화.
4. 카메라·마이크 권한 거부 후 설정에서 허용 → 재시도.
5. 수 분간 촬영: 발열·프레임 누락·음성 지연과 실제 용량 증가량.

## 후속 개선 후보

- 예기치 않은 강제 종료 후 부분 MOV를 앱 안에서 탐지·검사하는 복구 화면. 현재는 파일 앱에서 수동 확인.
- 프레임 누락 수·현재 해상도·남은 저장 공간 표시. 현재 프레임이 밀리면 영상 프레임은 누락될 수 있음.
- 지원 아이폰별 장시간 촬영 측정과 화질·프레임률 선택. 현재 기본 720p·30fps, 필요 시 480p로 낮춤.

자동 테스트는 실제 카메라 하드웨어·지역별 시스템 소리·화면 밝기·전화·잠금·발열을 대신 검증하지 않습니다. iOS가 백그라운드 저장 시간을 회수하거나 앱이 강제 종료되면 완전한 저장을 보장할 수 없습니다.
