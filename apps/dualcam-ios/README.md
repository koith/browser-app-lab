# DualCam

저장소 위치: [`koith/browser-app-lab/apps/dualcam-ios`](https://github.com/koith/browser-app-lab/tree/main/apps/dualcam-ios)

빌드 실행·결과: [GitHub Actions → DualCam iPhone IPA](https://github.com/koith/browser-app-lab/actions/workflows/dualcam-ios.yml)

전면·후면 카메라 영상을 **동시에, 각각의 MOV 파일로 녹화**하는 개인용 네이티브 iPhone 앱입니다. 두 영상 모두 같은 마이크 음성을 포함합니다. 시작·종료 효과음을 재생하는 코드는 넣지 않았습니다.

## 구현된 기능

- `AVCaptureMultiCamSession`으로 전면·후면 동시 촬영.
- 기본 720p·30fps. 기기의 처리 한도가 부족하면 480p·30fps로 낮춤.
- H.264 영상 + AAC 음성. 두 파일에 동일한 시작 시간 기준을 적용.
- **녹화 시작 → 검은 화면**을 눌러 화면을 검게 표시하고 밝기를 최소화.
- 검은 화면을 **두 번 탭**하면 조작 화면으로 복귀. 정지 버튼으로 저장.
- 녹화 목록, 전면·후면 재생, 공유, 삭제 확인.
- 파일 앱 → **나의 iPhone → DualCam → Recordings**에 원본 파일 보관.
- 화면 잠금, 앱 비활성화, 전화 등의 중단 시 녹화 종료·저장 시도.
- 저장 공간 부족·위험한 발열 상태 감지 및 종료.
- 외부 서버 업로드, 광고, 분석 SDK 없음. 녹화 파일은 기기에 저장하며 기기 백업에서는 제외.

## 지원 범위와 실제 검증이 필요한 부분

- **iOS 16 이상**이며 Apple의 전·후면 MultiCam 조합을 지원하는 iPhone이 필요합니다. iOS 버전만으로 지원이 결정되지는 않습니다. 앱이 실제 기기 지원 여부를 검사합니다.
- 검은 화면은 **앱이 표시하는 검은 화면**입니다. 실제 화면 전원 끄기·잠금 중 녹화는 지원하지 않습니다. 앱이 비활성화되면 저장을 마무리합니다.
- iOS의 카메라·마이크 개인정보 보호 표시를 변경하거나 숨기지 않습니다.
- 앱 효과음은 없지만, **판매 지역·모델·iOS에서 강제하는 소리가 있는지는 실제 기기로 확인해야 합니다.** 모든 기기에서 완전한 무음을 보장한다고 검증한 상태는 아닙니다.
- 세로 방향으로 촬영합니다. 전면 미리보기는 거울처럼 표시하고, 저장 영상은 좌우 반전하지 않습니다.
- 같은 시간 기준을 쓰지만 두 카메라가 같은 순간에 프레임을 노출한다고 보장하지는 않습니다. 부하가 크면 프레임이 누락될 수 있습니다.
- 강제 종료·전원 차단 시 저장은 보장되지 않습니다. MOV를 주기적으로 조각내 기록하지만 손상 방지를 보장하지는 않습니다. 저장 오류가 나면 부분 파일을 삭제하지 않습니다. 파일 앱에서 확인할 수 있습니다.

## 현재 검증 상태

이 소스는 Linux 작업 환경에서 만들었습니다. Swift 9개 파일의 구문 분석, Xcode 프로젝트 구조, plist·워크플로·스크립트 검사와 패키징 검사를 수행했습니다.

**현재 환경에는 Xcode·iOS SDK가 없으므로 Xcode 컴파일, 아래 XCTest 실행, 실제 iPhone 촬영 검증은 아직 수행하지 않았습니다. 설치 가능한 IPA가 이미 만들어진 상태는 아닙니다.** GitHub Actions는 이 검증과 빌드를 수행하도록 작성되어 있습니다. 첫 실행에서 Xcode의 형식·API 검사에 따른 수정이 필요할 수 있습니다.

## 맥 없이 GitHub에서 빌드하기

1. 앱 소스는 이 저장소의 `apps/dualcam-ios/`에 있고, 워크플로는 저장소 루트의 `.github/workflows/dualcam-ios.yml`에 있습니다.
2. GitHub에서 **Actions → DualCam iPhone IPA → Run workflow**를 실행합니다. 이 앱 소스 변경을 push해도 실행됩니다.
3. macOS 러너가 아래 테스트를 실행하고, iPhone용 앱을 서명 없이 빌드합니다. Apple 계정·인증서를 GitHub에 넣을 필요가 없습니다.
4. 성공한 실행의 **Artifacts → DualCam-unsigned-IPA**를 내려받아 ZIP을 풉니다.
5. 안에 있는 `DualCam-unsigned.ipa`를 Windows에서 서명·설치합니다.

GitHub Actions의 macOS 실행은 계정의 무료 제공 범위와 사용량에 영향을 받습니다. 무제한 무료를 보장하지 않습니다. 비용 설정과 잔여 사용량은 GitHub에서 확인합니다.

### 자동 테스트

- 두 카메라의 첫 프레임 시각이 달라도 같은 시간 기준을 적용하는지.
- 중복·역순·잘못된 타임스탬프를 거부하는지.
- 합성 영상·음성을 넣어 **전면·후면 MOV 모두 실제 영상 트랙과 디코딩 가능한 AAC 음성을 포함하는지**.
- 두 번째 카메라가 준비되기 전에 종료하면 성공으로 처리하지 않는지.

시뮬레이터 테스트는 카메라 하드웨어·시작/종료 소리·발열을 검증하지 않습니다. 아래 실제 기기 검증을 별도로 해야 합니다.

## Windows에서 설치

1. [Sideloadly 공식 사이트](https://sideloadly.io/) 또는 [AltStore Classic 공식 안내](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)를 이용해 설치 도구와 필요한 Apple 드라이버를 준비합니다.
2. 처음에는 iPhone을 USB로 연결하고 기기에서 **이 컴퓨터 신뢰**를 승인합니다.
3. 무료 Apple 계정으로 IPA에 서명해 설치합니다. Apple 계정 암호는 이 프로젝트나 GitHub에 입력하지 않습니다.
4. 필요하면 iPhone에서 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 활성화하고, **설정 → 일반 → VPN 및 기기 관리**에서 개발자를 신뢰합니다.
5. 앱을 열어 카메라와 마이크 권한을 허용합니다.

무료 계정 서명은 일반적으로 **7일마다 갱신**해야 합니다. 갱신할 때마다 소스를 다시 빌드할 필요는 없습니다. 도구의 Wi-Fi 페어링 설정을 완료하면 같은 네트워크에서 무선 설치·갱신이 가능하지만, Windows와 해당 설치 도구는 실행 중이어야 합니다. **설치 후 앱 사용과 카메라 테스트에는 PC 연결이 필요 없습니다.**

영상이 필요하면 앱 삭제 전에 파일 앱이나 공유 기능으로 복사해 두세요. 앱 삭제는 내부 녹화 파일도 삭제할 수 있습니다.

## 첫 실제 기기 테스트

1. 10초 이상 녹화한 뒤 종료합니다. 전면·후면 영상이 모두 재생되고 각각 음성이 들어가는지 확인합니다.
2. 녹화 시작·종료 시 들리는 소리가 있는지 확인합니다. 무음 스위치 상태와 기기·iOS 버전도 기록합니다.
3. 녹화 중 검은 화면으로 전환하고, 두 번 탭해 복귀합니다. 밝기가 이전 값으로 복원되는지 확인합니다.
4. 녹화 중 잠금 버튼을 누른 뒤 다시 엽니다. 녹화가 종료되고 두 파일이 저장되는지 확인합니다.
5. 수 분간 녹화하며 음성 지연·프레임 누락·발열·용량을 확인합니다. 중요한 녹화 전에 이 단계를 완료합니다.

## Mac이 있는 경우

`apps/dualcam-ios/DualCam.xcodeproj`를 Xcode에서 열 수 있습니다. 개발 팀을 지정해 직접 설치하거나 저장소 루트에서 아래 명령을 실행합니다.

```bash
cd apps/dualcam-ios
bash scripts/test_ios.sh
bash scripts/build_unsigned.sh
```

프로젝트 파일은 `python3 scripts/generate_project.py`로 재생성할 수 있습니다. Swift 파일을 추가해도 별도 패키지 설치 없이 프로젝트에 반영됩니다.

### 주요 파일

- `DualCam/CaptureController.swift`: 카메라·마이크 연결, 권한, 녹화·중단 처리.
- `DualCam/DualMovieWriter.swift`: 두 MOV의 영상·음성 인코딩과 저장.
- `DualCam/ContentView.swift`: 조작 화면·검은 화면·밝기 복원.
- `DualCam/RecordingLibrary.swift`: 재생·공유·삭제.
- 저장소 루트의 `.github/workflows/dualcam-ios.yml`: macOS 테스트·미서명 IPA 빌드.

화면 잠금 녹화, 강제 시스템 소리 제거, 개인정보 보호 표시 우회는 포함하지 않습니다.
