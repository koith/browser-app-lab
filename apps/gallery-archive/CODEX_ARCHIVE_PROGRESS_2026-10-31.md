작품별 SHA가 다른 묶음과 겹칠 수 있으므로 전체 고유 수량은 전체 인덱스 집계를 따른다. 주요 공개 웹판 보충 수량은 위 작품별 신규 SHA로 집계했고 소규모 판본·재인코딩 파일을 새 포즈로 보고하지 않는다. The Pet Girl과 The Pet은 별개 작품이다. 심유이는 신규 저장과 기존 2장 고해상도 교체를 구분했고 더 큰 기존 원본을 낮은 웹판으로 덮어쓰지 않았다.

가장 많은 실물 보충을 만든 방법은 일반 공개 페이지네이션과 기존 사진 3개 이상의 전체 화면 대조다. 별도 영어 출처의 공개 개별 이미지 배열도 사용했다. 역이미지·다국어 검색에서 발견한 페이지 수를 저장 사진 수로 바꾸어 보고하지 않았다.
대규모 웹판 보충은 주로 긴 변 1368px, Summer Vol.5는 1440px이다. 워터마크가 남은 파일도 있다. 이를 발행사 4K/8K 최고 마스터로 표시하지 않았다. 원 응답 바이트 보존, 원본 손실 재압축·업스케일·워터마크 제거 없음, 이번 등록 사진은 원본과 별도 미리보기의 검증을 모두 통과했다. 미리보기만 실패한 정상 원본의 추가 등록은 별도 승인 대기이며 실행하지 않았다.

## 엔진·보관 수정

- 파일별 재개·중복 방지·보수적인 CDN 재인코딩 검증·실제 공개 원 크기 링크 추출을 유지·확장했다. 다른 모델·관련 게시물·인용 게시물·광고를 제외한다.
- 작품 대응·디코딩·해상도·길이·SHA를 확인한 파일만 기존 개인 보관소에 저장했다. 미확정 대응 사진은 보류했다. 비공개 경로·쿠키·토큰·원본을 공개 저장소에 올리지 않았다.
- 업로드→원격 SHA 확인→비공개 대기→독립적인 재검증→원본 목록 발행을 연결했다. 수집 중 발행이 전수 검사를 취소시키던 문제를 피하도록 검사 완료 후 대기분을 발행했다.
- TeraBox 400141 응답은 이미지로 받아들이지 않는다. 기존 동일 계정의 정상 Cookie 헤더 형식을 복구했으며 추가 확인 응답을 다른 인증·도메인 재시도로 우회하지 않는다.
- 전송 전 출처·사진 번호 기록을 같은 개인 보관소에 검증 미완료 상태로 먼저 보존한다. 다른 작품 실패 시에도 원본과 미리보기 전체가 원격 SHA 검증된 작품만 별도 비공개 대기로 보존할 수 있다. 실패한 수집 작업은 실패로 남고 정상 발행기가 다시 전수 검증한다.
- 별도 미리보기만 실패한 밈미 원본을 기존 원본 경로로 직접 썸네일에 쓰는 코드를 병합했다. 거부된 원본·미리보기 재요청이나 재업로드는 하지 않는다. 실제 추가 실행 요청은 개인 보관 기록의 GitHub 전송에 대한 자동 검토 거부로 미게시 상태이므로 그 후보를 확보 장수에 세지 않았다.
- 연속 구간 검사로 불필요한 중간 썸네일 요청을 줄였다. 완료된 네이티브 작업의 실제 로그·전체 사진 조건·현재 순서·원본/미리보기 메타데이터가 일치할 때만 이어받았다. 실패·취소 작업의 부분 결과와 이어받기 포인터는 신규 성공으로 세지 않았다.

## 실제 갤러리 QA

모든 변경 항목에서 실제 썸네일·확대·사진 열기 탭을 디코딩하고, 브라우저 다운로드 이벤트로 받은 파일의 SHA와 길이를 확인했다. 양쪽 갤러리의 모든 저장 항목이 올바른 작품 안에 표시되는지도 검사했다. 같은 작품 안의 바이트가 동일한 중복만 표시 경로를 공유할 수 있다.
실제 모바일 크기 Chromium·WebKit에서 다음/이전·고정 닫기·브라우저 뒤로가기·새로고침을 확인했다. 이미지 105초 및 작업 24분 제한을 늘리거나 실패 조건을 제거하지 않았다. 이전 원본 탭 로딩 실패는 실패로 남겼으며, 최종 통과 수는 실제 완료된 브라우저 기록만으로 집계했다.
실기기 iPhone의 핀치·길게 누르기는 미수행이다. 전체 발행사 마스터가 확보됐다는 주장은 하지 않는다.

- Render의 닫힌 업로드 기능 재활성화와 비공개 메타데이터 GitHub 전송은 자동 승인 검토가 거부해 수행하지 않았다. 기존 인증 Actions 보관 경로를 사용한다.
- 이번 원본·미리보기 쌍 검증에서 밈미 74장·심유이 1장을 보류했다. 미리보기만 실패한 원본의 추가 등록 요청은 민감 메타데이터 GitHub 전송에 대한 자동 검토 거부로 게시되지 않았으며 추가 확보 수량에 포함하지 않았다.

Your Panties 공개 웹판 325개와 발행사 표기 386개 등 서로 다른 판본의 총량을 혼동하지 않는다. 번호가 확인되지 않은 작품은 별도 비공개 집계에 구분했다. 차선 경로는 정상 접근 가능한 독립 공개 판본, 발행처·행사·사진가의 명시된 공개 원문, 사용자가 정당하게 보유한 원본의 기존 보관소 연결이다. 인증·결제·캡차·법적 접근 제한 우회, TinyFish·유료 크롤러·사진 ZIP 경로는 사용하지 않았다.
