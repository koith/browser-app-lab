# 심유이·밈미 미확보 화보 원인 분석 및 회복 우선순위

검토 기준: 2026-10-30, `main`의 SHA-기록 보관 목록 및 실제 GitHub Actions 로그. **페이지 발견, 이미지 URL의 과거 HTTP 검증, Actions ZIP 생성, 실제 TeraBox 원본 보관, 공개 갤러리 디코딩**은 서로 다른 단계다. 중간 단계는 사진 확보 실적이 아니다.

## 검증된 기준선

| 지표 | 밈미 | 심유이 |
|---|---:|---:|
| TeraBox 비공개 원본 인덱스 | 73개 앨범, 3,213개 사진 번호 | 30개 앨범, 2,999개 사진 번호 |
| GitHub Pages 실제 커밋 이미지 | 64개 앨범, 2,243장 | 6개 앨범, 23장 |
| 비공개 앨범 중 40장 이하 | 51개 | 10개 |
| 최근 Chromium/WebKit 배포 갤러리 화면 사진 수 | 3,178개(중복 작품/번호 통합) | 3,022개 |

공개 파일과 비공개 인덱스를 합산하면 중복된다. 원본 인덱스 사진 번호도 화보 원판 전체 확보의 증거는 아니다.

- 광역 공개 자료 등록 20개 소스, 그중 읽기·파싱 16개. 화보 제목 후보 그룹 101개, 공개 물리 저장본 제목과 정확히 일치하지 않는 그룹 66개. **이 66개는 미확보 작품 수가 아니다.** 제목·표기·판본 ID 통합 전의 후보만 뜻한다. 글로벌 수집 액션 `41018378329`.
- DJAWA 밈미 공식 작품 32개, 공개 샘플 URL 586개. 발행처가 사진 수를 밝힌 16개 중 14개에서 발행처 표기 수량이 보관 수량을 초과하며, 그 차이의 합은 **1,641개 사진 번호**. 각 작품의 판본/장수 정책 확인 전에는 확정 미확보 고유 이미지 수가 아니다.
- 밈미 10장 내외 V2PH 공개 미리보기 상당수는 **발행처 완전판과 다른 무료 공개 영역**. 크롤러 재시도를 늘려도 없는 이미지가 생기지 않는다.

## 실패 유형별 근거·해결책

### A. 작품은 발견했으나 완전판 이미지가 공개되지 않음 — 가장 큰 잔여 격차

예시 (발행처 표기 / TeraBox 번호 / 차이):
- Nikke : Yuni **213 / 15 / 198**
- Rei, Beyond the Heart **213 / 44 / 169**
- My Summer Vacation Vol.2 **183 / 18 / 165**
- Twin Bunnies Affair **157 / 17 / 140**
- Le Malin – Listless Lapin **158 / 25 / 133**
- My Summer Vacation **149 / 19 / 130**
- Christmas Witch 2025 **151 / 29 / 122**

대책: 작품별 정식 발행 ID·판본·예상 수량을 확정하고, 무료 공개 이미지의 **모든 페이지·지연 로딩·공식 별도 공개 미리보기**를 추가 수집. 최종 잔량은 적법하게 접근 가능한 발행처 전체판 또는 사용자가 이미 보유한 원본 매체와 대조·반입한다. 페이월 안의 원본은 외부 공개 수집기만으로 보충 가능한 자료라고 가정하지 않는다. 완료 표기는 보관 파일/발행처 버전별 실제 번호 대조 후.

### B. 다운로드는 성공(HTTP 200)인데 과거 SHA와 현재 전송본이 다름

`41021268304`: 당시 누락 후보 44개 전부 유효한 이미지였으나 재인코딩으로 SHA가 바뀜. `cdn.v2ph.com` JPEG 35개와 Gumroad WebP 9개. JPEG 35개는 동일 URL·해상도·품질/바이트 조건·Pillow 디코딩·새 SHA 검증으로 실제 저장, TeraBox 원격 SHA 재검사 70/70 통과. 밈미 3,178 → **3,213장**. `41021487174`.

Gumroad WebP 9개는 일부가 과거 78~293KB에서 현재 8.5~39KB 수준으로 급격히 축소되어 *원본 복구가 아닌 저품질 대체품* 우려가 있다.

대책: ① 원본 URL의 현재 변형이 참된 작품 이미지인지 퍼셉추얼 해시·픽셀 유사도/구조적 유사도 및 품질 기준으로 검증 ② 동일 작품의 공식 공개 샘플·다른 정상 공개 소스에서 **실제 프레임**을 확보 ③ 새로운 SHA를 정확히 기록하고 기존 저장본은 보존. 검증되지 않은 이미지/자리표시자/워터마크로 장수를 채우지 않는다.

### C. 자료 제공 사이트가 불안정하거나 일부 페이지가 공개되지 않음

- V2PH 배우 페이지에서는 39개 앨범을 찾았지만 일부 후속 사진 페이지는 HTTP 404 등으로 중단, 10장 미리보기 수준의 작품 존재. `41019275389`.
- 밈미 공개 SNS 대체 페이지는 Twstalker HTTP **403**, Twoucan **503**, 확인된 신규 저장 **0장**. 심유이 teapawt 공개 페이지는 69개 이미지 URL 후보를 표면에서 검출했지만 아직 작품 식별·실제 파일 저장 증거 없음. `41022019249`.
- 해외 미러·인덱스는 0사진 작품 제목만 나열하거나 다른 광고/추천 이미지가 섞여 있다. Yui 일부 jliji 원본은 이전에 **451** 응답이 확인돼 수집 대상에서 제외됨.

대책: HTTP 정적 사이트는 Scrapy `JOBDIR` 체크포인트와 도메인별 rate-limit/재시도 정책, 일반 공개 무한 스크롤·다음 페이지는 Playwright, 지원되는 SNS는 gallery-dl 아카이브 활용. 401/403/451/페이월은 우회가 아닌 공식 공개 경로·권한 있는 원본으로 전환. *페이지 존재와 이미지 저장을 구별*.

### D. 같은 작품의 다른 철자/언어/발매 버전/이미지 SHA가 중복 또는 누락으로 잘못 계산됨

DJAWA의 Rudy² 항목은 연구상 ID `djawa-rudy%c2%b2-codename-wolfgirl`이지만 보관 ID `djawa-rudy2-codename-wolfgirl-9b4e68`에 **218개 사진 번호**가 이미 있음. 제목의 정확 일치만으로 “완전 미확보”라고 보고하면 오류다. PixiBB의 반복 이미지·V2PH 예고편·Xiutu 재배포가 원작과 겹친다.

대책: 발행사, 촬영/작품명, 권, 발매판, 촬영일로 작품 정규 ID를 만들고 **명시적으로 검증한 별칭**으로 연결. 이미지 파일은 SHA+픽셀 유사도+번호/판본을 각각 기록하고, 이미지가 달라졌다는 이유만으로 기존 번호를 덮어쓰지 않는다. 닮은 제목만으로 합본하지 않는다.

### E. 원본 수집은 됐는데 보관/사용자 화면 검증으로 이어지지 않음

과거 TeraBox incremental workflow의 깨진 YAML/중복 끝부분으로 클라우드 반입 작업이 시작되지 않았음. PR #327에서 복구했고 SHA 원격 재확인에 성공. 현재 원본 인덱스는 배포 사이트에 반영됐음.

반면 독립 QA 중 일부는 낡은 앨범 수 비교(`36 vs 64`), 이미지 `src` 미설정 상태 또는 `crawl_pages` 함수 ImportError로 실패. 이는 실제 특정 사진의 부재와 구별해 재현·수정해야 한다. 최신 대표 앨범 배포 QA `41021795272`는 Chromium·WebKit에서 카드, 썸네일, 라이트박스, 새로고침 통과했지만 **수천 장의 전수 디코딩 증명은 아니다**.

대책: 실제 개별 원본을 비공개 스토리지에 영구 저장, SHA/크기/디코드 확인, 원격 readback, 보관 인덱스 갱신, 모바일 전수/샘플 QA를 각각 별도 단계로. ZIP은 Actions 임시 반송 포맷일 뿐 영구 화보 저장 형태나 사용자 UI가 아니다. 브라우저 캐시/렌더 서비스 실패를 사진 미확보로 혼동하지 않는다.

## 실행 우선순위 및 성공 조건

1. **완전판 잔량이 큰 작품부터** 공식 기대 수량·저장 번호·정식 출처·기확보 원본을 결합한 작품별 미확보 매트릭스 작성. 정확한 판본·별칭 대조 전의 제목 후보를 누락 작품으로 확정하지 않음.
2. **이미 공개된 현재 이미지 회복**: Gumroad 재인코딩 9개는 저품질 임시 저장 대신 고품질의 동일 프레임 확인부터; 중국/일본/한국 공개 소스의 진짜 다음 페이지까지 순회; 가능한 경우 계정 소유자/발행처의 일반 공개 게시물 수집.
3. **작품당 동시 소스 수집기**: 정적 HTML/Scrapy + 정상 공개 동적 페이지/Playwright + 지원 미디어/gallery-dl. 소스별 체크포인트, 상태 코드·이미지 질적 실패 사유, 중복 해시와 취소/재개 가능 상태 기록.
4. **임시 ZIP 의존도 축소**: 영구 단위는 이미지 파일 1장/번호 1개. 클라우드 업로드 뒤 SHA readback, 인덱스 자동 반영, 갤러리 렌더 체크를 한 작품 단위로 닫아야 함.
5. **정직한 통계**: `찾은 작품 / 제목만 확인 / 공개 URL 발견 / 실제 다운로드 성공 / 원격 SHA 검증 / 사용자 화면 디코드 / 발행판 대비 확인된 미확보`를 분리. 사용자 갤러리에서는 정상 열리는 저장본만 표시.
