# 밈미 갤러리 개발·아카이빙 인수인계서

작성 기준: 2026-10-29 (KST) · 프로젝트: **화보** · 저장소: `koith/browser-app-lab`

## 1. 사용자 확정 요구사항

1. **밈미(Mimmi) 갤러리는 심유이(YUI) 갤러리 최신 UI와 같은 형식**으로 표시한다. 2026-10-29 07:36 KST에 사용자가 제공한 심유이 `v0.1.0-beta.19` iPhone Safari 스크린샷이 직접 기준이다. 검정 배경, 상단 `YUI / GALLERY` 스타일 워드마크, 우측 검색, 바로 아래 `총 사진 수 · 미리보기 수` / `N albums` 위치, `화보 ⇄ 발행처` 토글, 모바일 2열 표지, 좌상단 발행처·장수, 우상단 웹판 배지, 하단 화보 제목을 맞춘다. 단, **밈미의 미리보기·총장수는 실제 저장된 파일만 집계**하고 검증만 된 링크는 집계 금지.
2. 심유이 갤러리는 Codex가 별도 작업 중이므로 **`apps/yui-gallery/`는 수정하지 않는다**. 밈미의 `심유이 ↗` 전환은 새 탭 `target="_blank"`로 연다.
3. **화보당 10장 샘플 수집 금지.** 전체 공개 페이지, 페이지네이션, 일반 브라우저 스크롤, 다른 공개 출처 교차 확인을 병행한다. 화보마다 실제 수십~수백 장을 채우는 것이 목표지만 유료·비공개 원본을 우회하지 않는다.
4. **무료 도구만 사용.** GitHub Actions, Python requests/BeautifulSoup/Pillow, Playwright Chromium/WebKit, 정적 GitHub Pages. TinyFish 유료 브라우저, TeraBox, Render 게이트웨이는 필요 없다.
5. **갤러리에는 저장되어 실제 표시되는 사진만.** 공개 URL을 검증한 개수나 연구 대상 화보 수를 저장 실적으로 표기하지 않는다. 물리 파일, SHA-256, 이미지 디코딩, iPhone WebKit 표시를 구분 검증한다.
6. 이미지 재게시·공개 호스팅 권한은 별도로 확인해야 한다. **GitHub Pages에 올라간 파일은 누구나 접근 가능**하며 개인 비공개 아카이브가 아니다. 비공개·유료 원본을 무단 다운로드하거나 제한을 우회하지 않는다.

## 2. 실제 저장 현황 (작성 시점 main)

- **물리 저장 1,510개 이미지 파일 / 39개 화보**: `apps/mimmi-gallery/stored-albums.json`의 `physical_verified_image_count` 및 `albums`에서 확인. 이 수치는 2026-10-29 KST 작성 시점의 스냅샷이며 다음 실행에서 달라질 수 있다.
- **CreamSoda 5개 실저장 화보**: Chic Nerd & Maness Nurse 63장, Neko Mimmi 62장, Mashu Mimmi 59장, Belt choker 46장, Mash Mimmi 2 72장.
- 기타 주요 실저장 화보: Girls' Frontline HK416 254장, Rudy The Wolf of Midnight 248장, Nikke Alice 150장, Christmas Special 2021 118장.
- `xiutu-public-previews.json`의 6개 화보·373개 SHA 검증 공개 URL은 **수집 검증 기록**이며, 저장량으로 따로 더하면 중복 계산이다. 저장 인덱스에 반영된 것만 갤러리 집계에 포함한다.
- 저장 상태가 **발행사 원본 완전판 확보**를 의미하지는 않는다. 공개 웹 이미지가 발행사 발행 수량과 정확히 일치하는지 화보별 추가 검토가 필요하다.

## 4. UI 적용사항과 검수 기준

- 심유이 `beta.19`의 모바일 **2열 카드, 워드마크, 배지, 화보 토글, 상단 숫자 위치**에 맞춰 밈미 CSS를 조정했다.
- 상단 기술적인 `이 기기에서 사진 로딩...` 상태 표시를 제거해 YUI 화면처럼 한 줄로 표시한다. 실제 네트워크 로딩 오류 감지 코드는 유지한다.
- 기본 모드는 `albums`; 검색, 발행처 토글, 사진 상세·라이트박스, 이전/다음, Safari 화면 폭과 새 탭 이동은 유지한다.
- 인벤토리는 `N장 · 실제 저장본`; `N albums`는 실제 파일이 있는 카드만. 연구용 외부 URL/미저장 화보를 카드로 출력하지 않는다.
- 갤러리 버전 표기: `v0.1.0-mimmi.9`. 테스트 `test_mobile_album.cjs`는 2열, 워드마크, 새 탭, 로컬 사진 경로, SHA 파일 존재 여부를 확인하도록 갱신.

## 5. 중요한 미완료 사항

1. **UI 배포·실기기 최종 검증**: 이 문서와 UI 변경 PR을 main에 병합하고 GitHub Pages 배포 성공 여부를 확인한 후, 사용자 iPhone Safari 스크린샷과 실제 화면을 비교한다. 현재 이 문서는 설계/코드 변경 기록이며 최종 사용자 실기기 검수를 대신하지 않는다.
2. **전체 화보 보충**: 10장으로 남은 DJAWA/V2PH 작품을 우선 재조사하고 공개 출처 간 동일 판본·중복 사진·누락 번호를 대조한다. 화보 발행사 수량은 단순 페이지 표기만으로 완전판이라 판단하지 않는다.
3. **저장 공간**: `publish_stored_public.py`에 공개 Pages 파일 예산 `MAX_PUBLIC_IMAGE_BYTES=780*1024*1024`이 존재한다. 용량 부족 시 무단으로 비공개 파일을 공개 Pages에 옮기지 말고 공개 호스팅 권한·용량 정책을 확인한다.
4. **대체 출처와 실제 파일 구분**: `source-viewer-albums.json`의 검증 SHA URL은 사진 보관을 뜻하지 않는다. `stored-albums.json`과 실제 파일 경로가 일치하고 해시·이미지 디코딩·브라우저 로딩이 통과한 것만 실적에 포함한다.
5. **YUI 비간섭**: 심유이 폴더와 심유이 자동화는 변경 금지. 밈미와 심유이 간 이동만 새 탭 연결한다.

## 7. 후임 개발자에게 전달할 우선순위

**1순위**: UI 병합 후 모바일 2열·실저장 숫자·사진 실제 로딩·심유이 새 탭 검수.

**2순위**: 10장으로 남은 화보를 다중 페이지·스크롤·공개 다른 사이트로 재조사하여 실제 SHA 검증 파일을 추가 저장. 미저장 링크는 갤러리에 표시하지 않는다.

**3순위**: 화보별 발행사 원본 판본과 공개판을 혼동하지 않도록 메타데이터를 정리하고, 공개 재게시 권한 및 Pages 용량 정책을 검토.
